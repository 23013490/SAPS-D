DockSAP-Secure Digital Case Management System

purpose:
Academic project to digitize law enforcement case files and reduce operational data risks vs paper systems

Risks addressed:

Data Loss:
Migrated from paper to encrypted database

2.Unathorized Access:

3.information leakage:
popia aligned,designed principles for confedintiality+intergrity

My Role
Analyzed security risks,designed  access controls,implemented authentication features.focus was risk mitigation and data protection.


What the Project is all about

The project is all about a police docket system were files are always missing in a police.
in order to solve the problem we created a system as a team to convert the process of police checking the docket into digital way
of checking the docket.We used modern technologies such as Php,Html,Css,JavaScript, and  Python for facial Recognition.

How to run the Project

To run the project you have to  have visual studio code as an ide for writing code,and try to create files for html,css,javascript,and php files.
Try to download python and install some packages or tools such as pandas into a terminal.try to store all the files into htdocs in xampp to host the project as a local Server.
